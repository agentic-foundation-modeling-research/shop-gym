# Brand Name Allowlist

Curated list of fake brand names cleared for use as ShopArena product/sub-product
names, demo store names, or sibling project names.

All names below have been **triple-checked** and have no meaningful real-brand
collision (broad search + domain probes + scholarly-database checks) at the time
of writing (2026-04-26). The shortlist is the **top-10 safest** subset — names
where neither the compound nor any parent word has notable brand presence.
Re-verify before committing to a public launch / trademark.

> Scope: this file is **not** the same as the `brand_blocklist` referenced in
> `docs/specs/shop_arena/shop_gen.md`. The blocklist filters real brand strings
> *out* of generated catalogs; this allowlist names safe identifiers we may
> adopt *for ourselves*.

## Rejected (real brands — do not use)

- ShopDojo — small Shopify reseller exists
- ShopForge — multiple existing stores + a WooCommerce mobile-app product
- BazaarForge — Shopify Partner agency; **high collision risk**
- BazaarLab
- MerchantMatch — payment-processing brand
- BasketBattle — mobile game
- TillForge — active retail POS infrastructure platform (`gettillforge.com`); **high collision risk**
- Vendrome — phonetically identical to Vendôme (Paris square, Miami nightclub, luxury/jewelry usage)
- Vendalia — active Mexican online store (`vendalia.com.mx`)
- MarketMelee — tournament platform, advertising agency, Duke Nukem 3D level
- StockyardArena — common rodeo-venue naming (Fort Worth, Denver, etc.)
- Vendarena — active CZ/HU employee-benefits eshop (`vendarena.eshop` on opencart.cz)

### Trimmed during shortlist (round 4) — cleared verification but not in top-10 safest

- CartColiseum — `tcgcoliseum.com` (Coliseum Trading Cards) + many "Coliseum" venues
- AgoraDome — close to AgroDome (data centers) and Irisbus Agora dome lights
- AgoraPit — "Agora" parent widely branded (music venue, shelter, town center)
- Marketrome — incidental Shopee listing usage; reads as "Market in Rome"
- CartCrucible — Crucible Chemical Co. + Crucible Company are established brands
- Shoptheneum — Athenaeum is heavily used (clothing brand, bookstores, music)
- BarterBowl — Barter Design makes ceramic bowls; product-name confusion
