# header_navigation

The primary navigation row anchors a mega-menu pattern. Hovering or
focusing each top-level category opens a full-width panel with three
columns:

1. **Subcategories** — links into nested collection pages.
2. **Featured selection** — a curated set of two highlighted
   collections with thumbnail tiles.
3. **Editorial CTA** — a single marketing tile linking into a story
   page.

Submenus are two levels deep before reaching a leaf collection. The
panel closes on `Escape`, on outside click, and on focus leaving the
last interactive element.
