# homepage_sections

## Site shell
- Plain horizontal header with the wordmark on the left and three icon
  affordances on the right (search, account, cart). No announcement
  bar.
- Footer renders a single column listing menu, policies, and a
  newsletter sign-up.

## Homepage sections
1. Hero image with a single headline and one call-to-action button.
2. Featured-collection row showing the first four products from the
   default catalog.

The page renders with no popup modals, no announcement strip, and no
secondary editorial blocks. The viewport scrolls cleanly to the
footer.
