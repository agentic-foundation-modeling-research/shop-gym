# search_predictive

The header search icon opens an overlay input. Typing two characters
(`sa`, `st`) triggers a predictive suggestion panel that splits results
into two sections:

- **Products** — up to four product tiles with thumbnail, title, and
  price.
- **Collections** — up to two collection links.

Submitting takes the user to a full results page laid out as a grid
with the same filter rail as the collection pages.
