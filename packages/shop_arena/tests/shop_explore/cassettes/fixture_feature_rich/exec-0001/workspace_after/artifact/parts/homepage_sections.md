# homepage_sections

## Site shell
- Top announcement bar with three rotating messages.
- Header carries the wordmark, a primary navigation row with mega-menu
  dropdowns, and a right-aligned cluster of search, account, and cart
  icons.
- Footer renders four parallel link groups plus a newsletter sign-up
  form and a locale + currency selector.

## Homepage sections
1. Hero carousel (three editorial slides, autoplay, manual dots).
2. Featured-collection grid (eight tiles).
3. Editorial banner with two side-by-side panels and inline CTAs.
4. Featured-collection row spotlighting a single category (six tiles).
5. Editorial story block (image plus prose, reverse layout on alt
   sections).
6. Newsletter strip with copy and an inline email capture.
