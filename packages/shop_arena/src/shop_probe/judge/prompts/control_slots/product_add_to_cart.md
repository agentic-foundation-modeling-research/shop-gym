You are looking at a product detail page (PDP) of an online store.

Decide whether the page exposes an "add to cart" control — a button
or link an agent could activate to add this product to the shopper's
cart. Names like "Add to cart", "Add to bag", "Buy now", or
"Pre-order" all qualify. The control must be associated with the
product on this page.

Treat as **present** when a single primary control of this kind is
visible and identifiable. Treat as **not present** when the only
purchase path is external (e.g. "Find a store") or no such control
exists.

Set `name_used` to the control's accessible name. Set
`evidence_locator` to a short hint (e.g. "primary CTA button below
price").
