You are looking at the homepage of an online store.

Decide whether the page exposes a clearly-identifiable brand identity —
either a store name as text, a logo image with an alt-text/name that
identifies the brand, or both. The brand should be discoverable in the
header / nav region or as the first visible identifying element.

Treat as **present** when the brand is unambiguous (a single store name
appears, or a logo image carries the brand). Treat as **not present**
when the page shows no name and no recognizable logo, or when the
identity is buried below distracting promotional content.

Set `name_used` to the brand text you saw (or `null` if only a logo with
no accessible name). Set `evidence_locator` to a short hint a human
could use to find the element (a heading, role+name, or visual region).
